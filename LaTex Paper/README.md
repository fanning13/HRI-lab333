# Lab 3 paper sources

- `lab3_guidance_submission.tex` is the current submission and the authoritative description of the completed camera-informed adaptive-guidance study.
- `lab3_confusion_storytelling_draft.tex` is a legacy design archive documenting the earlier spoken confusion-storytelling proposal. It is retained as a record of the design process, but it is not the protocol used for the results reported in the current submission.

When implementing, testing, or analysing the completed experiment, use `lab3_guidance_submission.tex` as the source of truth. Do not combine the legacy proposal's conditions, measures, or procedure with the current study unless a new protocol change is explicitly agreed and documented.
