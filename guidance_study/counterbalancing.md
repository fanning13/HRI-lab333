# Counterbalancing

Each participant completes both cases and both guidance strategies. Case order and condition order are crossed, so a difference between conditions is not tied to one mystery or to always coming first.

The design brief's fourth assignment repeated fixed-point for the Ashcombe Star. That assignment would give the participant no camera-informed case. Order 4 below keeps the within-participant rule: one case in each condition.

1. Ashcombe Star / fixed-point, then Briarwick Watch / camera-informed.
2. Briarwick Watch / camera-informed, then Ashcombe Star / fixed-point.
3. Ashcombe Star / camera-informed, then Briarwick Watch / fixed-point.
4. Briarwick Watch / fixed-point, then Ashcombe Star / camera-informed.

`P01` uses order 1, `P02` order 2, `P03` order 3, `P04` order 4, and then the rotation repeats. A session started without `--participant` takes the next number after the highest hardware log. Practice runs with `--simulate` do not advance that number. Do not reassign an order after a session has started. If the sample does not divide evenly by four, leave the last orders short rather than repeating a person.
